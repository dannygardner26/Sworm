# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/).

## [Unreleased]

## [0.2.0] - 2025-01-15

### Added
- AI agent runtime with multi-provider LLM support (Anthropic, OpenAI, Gemini, Bedrock, Ollama)
- Global hotkeys via Win32 RegisterHotKey
- Voice commands with Whisper speech-to-text
- Numbered agent system for quick focus switching
- Wallpaper mode (desktop-parent technique)
- Electron desktop app with terminal panes and widget system

## [0.1.0] - 2024-12-01

### Added
- CLI with deploy, kill, list, status, and monitors commands
- YAML formation system with zone, grid, and absolute positioning
- Multi-monitor support with monitor aliasing
- Worm types: claude, ide, app, generic
- Event bus for lifecycle hooks
